An agent has power. Give it a method. Skillify: engineering skills for AI coding agents.

orientify
Trace a real flow. Name the seams and traps.
undumbify
Supply decisions. Ask only what changes the outcome.
researchify
Official sources first. State confidence and gaps.
traceify
Falsify hypotheses before making the smallest fix.
audify
Set the standard. Reproduce every finding.
shapeify
Name the files, checks, dependencies and traps.
promptify
Set outcome, effort, scope and stop rules.
shipify
Set a baseline. Verify each step and the real result.
reviewify
Located findings. Concrete fixes. One verdict.
releaseify
Version from the diff. Rollback before deploy.
teachify
Match the learner. Explain, practise and check.

scout

researcher

worker
