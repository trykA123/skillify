# Skillify showreel

A 120-second, 1920 × 1080, 24 fps motion-graphics film with an original procedural score.

The narrative draws from Skillify's README, skills, agent definitions, and eval descriptions. All visuals and music are generated by `render.py`.

Rendering requires Python 3 with Pillow, FFmpeg with libx264 and AAC support, and the Inter and Adwaita Mono fonts at the paths configured near the top of `render.py`.

Render with:

```bash
python3 render.py
```

Inspect storyboard frames with:

```bash
python3 render.py --stills
```

The final deliverable is `skillify-showreel.mp4`. The 120-second structure is: request (0–12), ten skills (12–30), feature workflow (30–50), four agents (50–70), eval evidence (70–90), field feedback (90–108), and final identity (108–120). The score uses no sampled music.
